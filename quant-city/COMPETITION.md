# 量化董事会：比赛交付说明

## 核心体验

玩家在 3 天内完成 9 次直接交易决策。每次面对“板块上涨/下跌、回测是否可信、手续费、现金是否够用”等情境，在全额买入、小额试仓、暂不买入、先查数据之间选择。选择形成四类策略偏好：趋势、价值、防守、研究。序章结算后会推荐“趋势交易员、价值投资员、风险管理师、量化研究员”中的一个职业，玩家可接受、改选或继续担任董事长。

转职不是游戏终点。玩家会保留金币、城区、材料、职业角色等级、知识记录和历史画像进入下一赛季，继续完成新的三天九轮循环；事件 ID 带赛季编号，历史账本不会被覆盖。

策略偏好和知识水平分开计算。建设新城区前需要回答对应知识题，结果只用于粗略区分“入门小白 / 有经验投资者 / 研究型高手”；证据不足时显示“待观察”，并明确不代表真实投资能力。

## 评分标准对应

| 评分项 | 可核查实现 |
| --- | --- |
| 趣味性与体验 | 3 天 9 轮、抽卡、四角色、城区建设、次日资金返还、固定经营收益、移动端 H5 |
| 画像合理性 | 四类偏好由行为证据 ID 支撑；知识题单独计分；证据不足保留判断；用户可确认、拒绝或修改标签 |
| 个性化推荐 | 按最高策略偏好推荐 AI Skill / 策略库 / 因子库，按知识水平调整难度；每条包含理由和下一步任务 |
| Panda Data 价值 | 当前公开版使用可复现的合成行情，并明确标注；预留 `source / asOf / sector / priceChange` 事件字段接入真实数据 |
| 完成度与创新 | 互动 → 证据 → 偏好与知识画像 → PandaAIQuant 资源推荐 → 可执行下一步，完整闭环 |

## PandaAIQuant 结合点

1. **AI Skills**：趋势型用户推荐“趋势信号分析 Skill”，把自然语言想法转成进场、退出和验证任务。
2. **策略库**：价值型和防守型用户分别进入价值策略、低波动与仓位控制策略入口。
3. **因子库**：研究型或知识较高用户进入因子研究，继续检查数据发布时间、样本外表现和交易成本。
4. **课程中心**：知识证据不足或入门用户先进入公开课程中心，再返回游戏解锁城区。
5. **结构化画像**：导出的 JSON 包含行为证据、知识答题、推荐资源、理由和下一步任务，可供 PandaAI 产品流程消费。

当前比赛版没有声称已接入 Panda Data 或 PandaAI 生产资源目录。所有市场数据均为合成数据；AI Skills、策略库和因子库标注为“接入位/示例推荐”，公开按钮暂时指向赛事提供的课程中心。正式接入时需要 PandaAI 提供已审核的资源 ID、访问权限和数据字段说明。

## 两组演示路径

- 路径 A：连续选择全额买入，建设趋势港，答对趋势题。最终应显示趋势偏好较高，并推荐趋势 AI Skill；知识水平按实际答题数量显示，不能仅凭盈利判定高手。
- 路径 B：多次选择暂不买入或先查数据，建设防守园/研究院。最终应显示防守或研究偏好，并推荐仓位控制策略库或因子研究库。

评委改变一次关键选择后，对应偏好点数和推荐理由应同步变化；历史资金结果不会反向修改知识水平。

## 已知限制

- 不是实盘交易，不连接券商，不构成投资建议。
- 真实 Panda Data 尚未接入，不能把合成事件当成实时行情。
- 四道城区题只能做粗粒度知识分层，不能证明心理学或投资能力。
- 推荐入口需要 PandaAI 官方资源目录确认后才能替换为生产深链。
